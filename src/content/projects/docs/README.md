# Project authoring docs

Working notes, copy reviews, and stakeholder briefs that do not ship in the site. One folder per slug.

```
docs/
  ferpa-lima/
    README.md
    stakeholder-notes.md
    english-copy-review.md
```

Case-study JSON stays in the parent `projects/` directory. Images live under `public/images/assets/{slug}/` when a project has many assets (see `ferpa-lima/`, `cowboys-brief/`).
